# College Coursework: BE Computer Engineering

Lab experiments and practice code from my BE Computer Engineering coursework (Semesters 5–7), organised by semester and subject. Larger course projects live in their own repositories (see my profile).

| Semester | Subject | Highlights |
|---|---|---|
| 5 | Data Warehousing & Mining | Clustering, Apriori association rules, HMM / Viterbi (PGM) practicals |
| 5 | Software Engineering | Vehicle-management web app (HTML/JS) + Selenium end-to-end test suites |
| 6 | Artificial Intelligence | Agents, BFS and A* search |
| 6 | Cryptography & System Security | Caesar / Playfair ciphers, step-by-step AES implementation |
| 6 | System Programming & Compiler Construction | Parsing, three-address code generation, code optimisation, symbol table, Lex/Yacc |
| 7 | Big Data Analytics | Experiment scripts (main project: NYC TaxiPulse repo) |
| 7 | Information Retrieval | Text preprocessing & stemming, document clustering, pattern matching |
| 7 | Machine Learning | CART classification/regression, SVM kernel comparison, data reduction |
| 7 | Natural Language Processing | Bigram/trigram language models, stemmer, HMM / Viterbi POS tagger |

Scripts expect their data files in the same folder (`cd` into the folder before running).
A few large datasets are not included; the scripts name the file they expect.
